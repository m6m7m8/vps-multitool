# VPS Multitool v2 — Личный Gemini-бот под ключ

Минималистичный личный Telegram-бот на официальном SDK **`google-genai`**:
- **Вайтлист по Telegram ID** + **одноразовый 6-значный код привязки** (новичку даже не нужно искать свой ID).
- **PIN / пароль-замок** прямо в боте (3 ошибки → бан на 15 минут, автоблокировка по таймеру, удаление сообщений с паролем).
- **Гибкие настройки Gemini AI прямо из чата:** смена модели (`gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-4-argon`, `gemini-4-neon`, загрузка всех моделей с API или ввод своей), готовые роли и свой системный промпт, температура, длина ответа, переключение **Google Search (живой поиск в интернете)**, смена API-ключа прямо в боте.
- **Двойная компактная память:**
  1. **Скользящее окно диалога** (настраивается: 0, 6, 10 или 20 последних сообщений, сброс кнопкой `💬 Новый диалог` / `/clear`).
  2. **Долгая память фактов** (`/remember` или кнопка `🧠 Память`, до 25 коротких фактов о вас — сохраняются даже после `/clear` и аккуратно подставляются в системный промпт).
- **Понимает фото и документы** (`.txt`, `.py`, `.json`, `.csv`, `.pdf` до 5 МБ).

---

## Что нужно подготовить новичку (1 минута)
1. **Токен Telegram-бота:** откройте `@BotFather` → `/newbot` → скопируйте токен.
2. **Бесплатный Gemini API Key** *(можно взять сразу или добавить позже в настройках бота)*: откройте https://aistudio.google.com/apikey → **Create API Key**.

---

## Установка на чистый Ubuntu / Debian VPS

Подключитесь к серверу по SSH (`ssh root@IP_СЕРВЕРА`) и выполните **одну команду** *(после публикации на GitHub)*:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/m6m7m8/vps-multitool/main/install.sh)
```

Или если вы скопировали папку проекта на сервер вручную:
```bash
bash install.sh
```

Установщик сам поставит Docker, настроит `2 ГБ swap`, проверит ваш токен бота, спросит ID (или сам выдаст одноразовый 6-значный код привязки), по желанию поставит PIN и запустит бота.

---

## Управление на сервере (после установки)
```bash
multitool status    # статус контейнера
multitool logs      # логи в реальном времени
multitool restart   # перезапуск
multitool update    # обновление из GitHub
multitool reconfig  # поменять токен/PIN/ключи
```
